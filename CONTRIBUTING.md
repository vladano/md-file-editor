# Contributing

Thanks for helping improve MD File Editor.

## Setup

```bash
git clone https://github.com/vladano/md-file-editor.git
cd md-file-editor
npm install
npm start
```

Requires Node.js 20 or newer.

## Before you open a pull request

- Run `npm test`. All tests must pass.
- Put testable logic in `src/` and add or update tests in `test/`.
- Check UI changes by hand with the [test checklist](README.md#test-checklist).
- Keep pull requests focused on one change, and add a line to `CHANGELOG.md` under `Unreleased`.

## Reporting bugs and ideas

Use the issue templates. For a bug, include your OS, the app version and steps to reproduce. For security problems, see [SECURITY.md](SECURITY.md).
